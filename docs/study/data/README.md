# Study data (private)

Put the real study material here: `reports/` (anonymised report files R001.jpg …), `labels.csv`,
`clinician_ratings.csv`, `sus_responses.csv` and `task_log.csv` (copy the headers from `../templates`).

Everything in this folder except this README is ignored by git. Do not upload it anywhere public, even anonymised,
unless your ethics approval allows it.
